# Feature Spec: Canvas Shortcuts & UI Enhancements

## Overview
This specification details the addition of a new tutorial/shortcuts section in the AI Workspace sidebar and enhancements to the UI buttons to make them more professional.

## Requirements

1. **Shortcuts Tab**
   - Add a new tab named "Shortcuts" to the AI Workspace sidebar (`ai-sidebar.tsx`).
   - The tab will serve as an "Advice type" tutorial to help users learn canvas interactions.
   - Must include the following shortcuts:
     - `Backspace` / `Del`: Remove selected element
     - `Ctrl` + `Z`: Undo last action
     - `Ctrl` + `Y`: Redo action
     - `Space` + `Drag`: Pan around canvas
     - `Scroll`: Zoom in and out
     - `Double Click`: Edit node text
   - Design should use styled `<kbd>` tags for professional appearance.

2. **UI Enhancements (Professional Buttons)**
   - The Tab buttons in the AI Sidebar must look more professional.
   - Use rounded corners, smooth transitions (`transition-all duration-200`), and a subtle active state (`bg-[#2c2c30]`) with shadow effects.
   - Maintain the existing color scheme (dark theme, zinc/indigo/cyan accents) without breaking existing layout constraints.

## Constraints
- **Strict Scope**: Do NOT change anything extra apart from this. 
- Do not break the code or the project architecture.
- Just implement these specific features as requested.

## Status
- **Implemented**: The shortcuts tab and the professional tab buttons have been successfully implemented in `components/editor/ai-sidebar.tsx`.
